# Rain Drop Focus

Create a Pomodoro timer app. A big circular timer in the center showing 25:00. Three buttons: Start, Pause, Reset. When Start is pressed, the timer counts down. Add a clean modern design with a dark brown background. Title at the top saying 'Datarain cronômetro'. Use React with Vite
